# 🎬 Movie Listing App

A modern, fast, and responsive web application for browsing and discovering movies. Built with **Vite** and **TypeScript** for a smooth developer experience and snappy performance.

## ✨ Features

- 🎥 Browse a list of movies with posters, titles, and ratings
- 🔍 Search movies by title
- 📄 View detailed information for each movie
- 📱 Fully responsive design for mobile, tablet, and desktop
- ⚡ Lightning-fast development and build times powered by Vite
- 🧹 Linting with Oxlint for clean, consistent code

## 🛠️ Tech Stack

- **Framework/Tooling:** [Vite](https://vitejs.dev)
- **Language:** [TypeScript](https://typescriptlang.org)
- **Linting:** [Oxlint](https://oxc.rs)
- **Package Manager:** npm

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org) (v18 or higher recommended)
- npm (comes with Node.js)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com
   cd movie-listing-app
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. Open your browser and visit `http://localhost:5173` 🎉

## 📜 Available Scripts

| Command | Description |
| ----------------- | ------------------------------------ |
| `npm run dev`     | Start the development server         |
| `npm run build`   | Build the app for production         |
| `npm run preview` | Preview the production build locally |
| `npm run lint`    | Run Oxlint to check code quality     |
